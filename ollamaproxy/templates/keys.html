Vzory oddělené čárkou, * = cokoli. Vzor bez dvojtečky pokrývá všechny tagy (gemma4 = gemma4:12b i gemma4:latest). Dotaz na jiný model dostane 403 a v seznamu modelů (/api/tags, /v1/models) klíč vidí jen ty svoje — tím se projekt nedostane ani ke komerčním modelům.
0 = výchozí hodnota z Nastavení. Přes limit dostane aplikace 429 s Retry-After; limit za minutu platí pro průchozí dotazy i zadávání úloh.

Příklady

# čtení logu (role admin nebo client — client vidí log také)
curl -H "Authorization: Bearer opx_…" "{{ root }}/mgmt/v1/requests?since=24h&limit=20"
curl -H "Authorization: Bearer opx_…" "{{ root }}/mgmt/v1/stats?since=7d"
curl -H "Authorization: Bearer opx_…" "{{ root }}/mgmt/v1/models"

# dotaz na lokální Ollamu přes proxy
curl -H "Authorization: Bearer opx_…" {{ root }}/api/chat -d '{"model":"gemma4:12b","messages":[{"role":"user","content":"ahoj"}],"stream":false}'

# nečekat na uvolnění GPU (jiný model zrovna odpovídá) → 503 + Retry-After místo čekání
curl -H "Authorization: Bearer opx_…" -H "X-Opx-Wait: 0" {{ root }}/api/chat -d '…'

# požádat o načtení modelu; loaded:true = můžeš posílat, false = fronta/nahrává se (opakuj)
curl -H "Authorization: Bearer opx_…" {{ root }}/mgmt/v1/models/load -H 'content-type: application/json' -d '{"model":"gemma4:12b","wait_s":30}'

# odložená úloha pro agenta (odpověď klidně za 15 minut): id hned, výsledek přes GET /mgmt/v1/jobs/{id}
curl -H "Authorization: Bearer opx_…" {{ root }}/mgmt/v1/jobs -H 'content-type: application/json' \
  -d '{"path":"/api/chat","body":{"model":"gemma4:12b","messages":[{"role":"user","content":"ahoj"}]}}'
